HUONG DAN BIEN DICH TREN OVERLEAF (BAN TIENG VIET)
========================================================================

1. Tai tap tin 'ACAMIND_Vietnamese_Overleaf_Ready.zip' len Overleaf:
   - Truy cap Overleaf -> New Project -> Upload Project -> Chon file ZIP nay.

2. Trinh bien dich khuyen dung tren Overleaf:
   - Mac dinh: pdfLaTeX (ho tro Tieng Viet chuan qua goi vietnam / T5 fontenc).
   - Hoac co the chuyen sang XeLaTeX / LuaLaTeX (Menu -> Compiler -> XeLaTeX) neu muon.

3. Tap tin chinh (Main document):
   - Chon 'main.tex' hoac 'MaiPaper.tex'.
   - Nhan 'Recompile' de tao ban PDF Tieng Viet hoan chinh.
